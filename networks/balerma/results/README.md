# Curated Balerma results

The five objective MAT files and baseline MAT file are the authoritative saved
records used by the article. CSV files are human-readable derived tables;
ranking-cache MAT files permit extending a completed nested study without
rerunning earlier pipe counts. `cross_evaluation.csv` is written only after its
single-objective diagonal passes the convergence guard. See
`../../../docs/REPRODUCIBILITY.md` before overwriting a production result.
