# Balerma warm starts

`initial_designs.csv` contains one pipe-diameter vector per article objective.
The rows use exactly the `[PIPES]` order of `../input/network_original.inp`.
These vectors are warm starts, not reported results: every production result is
generated by MATLAB `ga` under `network_config.m` and validated against the
configured pressure constraints.

The table replaces dated INP files that were stored outside the reproducible
workspace. Keeping only link IDs and diameters makes the dependency portable,
compact, and easy to audit in a Git diff.
