# Reproducing the entropy and water-quality paper

This repository contains the MATLAB code, EPANET-compatible INP models, saved full-precision pipe designs, ranking caches, verification data, and figure/table procedures for *Flow and Chlorine-Weighted Entropy in Water Distribution Design: Boundary Effects, Diameter Ambiguity, and Failure Service*. The numerical solver is [STACI](https://github.com/hoscsaba/staci), revision `21816cb`. MATLAB calls its MEX interface with the network resident in memory. EPANET 2.2 is used for an independent replay of final designs, not as the optimizer's fitness evaluator.

## Start here

Use MATLAB R2026a with Optimization Toolbox and Global Optimization Toolbox. Build the STACI MATLAB MEX interface according to [its instructions](https://github.com/hoscsaba/staci/blob/master/matlab/README.md). From this repository root:

```matlab
startup
paper_root = pwd;
staci_root = '/absolute/path/to/staci';
mex_dir = '/absolute/path/to/staci/build-matlab/Matlab'; % contains staci_mex
validate_environment(staci_root,mex_dir)
addpath('manuscript/figures','manuscript/tables','supplementary')
reproduce_all_figures(staci_root,mex_dir) % saved designs; no network GA
export_manuscript_tables                % copies audited numerical tables
```

`validate_environment` checks the MEX binary, both toolboxes, all three fixed-load INPs and 17 final full-network MAT files. The separate Balerma 45-pipe branch-hop result is checked through its source MAT and table. `reproduce_all_figures` rebuilds computational figures from the saved designs. It also runs `make_portrait_submission_figures`, which stacks the already-rendered comparison panels for portrait journal pages without changing numerical results. The `*_portrait*.png` files are the submitted network figures; matching SVGs and original full-width composites are retained for inspection and editing. The four dense ranking matrices are exported as six portrait PNG sections each (`*_cost_{a,b,c}.png` and `*_objective_{a,b,c}.png`). The Supplementary LaTeX file sets their shared title, legend, and x-axis label at its 11-pt body size. Regenerate these sections after changing a ranking plot; they are crops of the saved full-resolution graphics and do not rerun optimization. `plot_cross_effects_portrait` draws separate, full-width six-by-six cross-effect panels for Anytown and Balerma from saved cross-evaluations and K=0 references; it does not run a solver. The Balerma branch-hop row is a restricted 45-pipe intervention, whereas its other five rows use full-network searches. The analytical pressure-boundary example and four-pipe examples are regenerated by their figure scripts; the chlorine example reads its saved pair unless explicitly called with `true`.

For independent cross-engine verification, add the bundled EPANET MATLAB Toolkit (`third_party/`) and run `supplementary/validate_staci_final_designs.m` on each final network. The published comparison CSVs are already included in `supplementary/results/validation_anytown_anchor_replay/` and `validation_staci_balerma_connected/`, with the Tanyimboh–Templeman record under `validation_staci_tanyimboh/`. The validator writes temporary case INPs and EPANET quality histories into its output directory. After validation, `python3 supplementary/render_validation_tables.py` formats the released GA-stop and STACI–EPANET CSVs into the Supplementary LaTeX tables under `supplementary/results/`. See [reproducibility instructions](docs/REPRODUCIBILITY.md) for exact calls and [methods](docs/METHODS.md) for numerical conventions.

## Which data are final?

| Network | Nominal boundary | Final designs and rankings | Failure replay |
|---|---|---|---|
| Tanyimboh–Templeman | Two stated source inflows | `networks/tanyimboh_templeman/results_staci/` | Benchmark and design comparison |
| Anytown | Pump/R10 supplies all demand; R65/R165 are zero-flow pressure anchors constrained to 215 ± 0.5 ft | `networks/anytown/results_staci_anchor_replay/` | Restore physical 215-ft R65/R165; 38 pipes × 3 reservoir availability states = 114 cases per design |
| Balerma | Four physical reservoirs 38/43/44/88 remain connected | `networks/balerma/results_staci/` | 454 single-pipe closures per design; source-free islands have zero delivered demand |

Five objectives are common to the three networks: cost, hydraulic flow entropy, squared chlorine concentration, chlorine-weighted flow entropy, and Todini's index. Tanyimboh–Templeman and Anytown also have full-network topology-only branch-hop-weighted entropy designs. Balerma has a **restricted** branch-hop design with 45 of 454 pipes free; do not compare it as a full-network optimum. The objective formulas and units are in [OBJECTIVES.md](docs/OBJECTIVES.md), and a figure/table-to-script map is in [MANIFEST.md](manuscript/MANIFEST.md).

The chlorine-directed designs impose at least 0.2 mg/L only at material-demand consumers (demand greater than the flow in a 10-mm pipe at 1 cm/s). The other designs report chlorine metrics without that constraint. Reported GA solutions are finite best-found designs, not proofs of global optimality. The stress-test frequencies are over enumerated cases, not annual failure probabilities.

## Recalculate designs

STACI reads each INP once, then candidate evaluation changes diameters through `setLinkProperty` and calls `solveHydraulics` and, when needed, `solveSteadyQuality`. Candidate evaluations do not write files. Each MAT file records the full-precision vector, objective, constraint violation, GA stopping data, and hydraulic/quality metrics. The saved vectors are deliberately retained so plots and EPANET checks do not require a stochastic GA rerun.

For Anytown, add `networks/anytown` to MATLAB's path and run `run_anytown_anchor_replay_optimizations(paper_root,staci_root,mex_dir)`. It audits and reuses existing endpoint MAT files; remove a chosen endpoint MAT only if you intend to rerun that objective. The bundled `cost_local_seed.mat` supports the narrow feasible region. The full discovery sequence, including ranked-subset continuation of the best-found entropy endpoints, is in [REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md). `run_anytown_anchor_replay_rankings` stores each `(objective, ranking, K)` point separately under `ranking_cache/`, so extending the pipe-count range does not rerun completed points.

For Balerma, [BALERMA_CONNECTED_RUN.md](docs/BALERMA_CONNECTED_RUN.md) gives the four-reservoir GA, ranking, outage, and review sequence. New GA results are first written to `results_staci_connected/`; the released, reviewed results are in `results_staci/`. Its per-point ranking cache also permits extension without recomputing earlier K values.

The Tanyimboh–Templeman branch-hop search is `run_tanyimboh_branch_hop_optimization(paper_root,staci_root,mex_dir)`; its frozen weights are in `branch_hop_weights.csv` and the result is the upper panel of Supplementary Figure S6. The reference-flow verification is analytical (`wdn.verify_tanyimboh_reference`). The same-flow, different-diameter construction is `manuscript/figures/make_tanyimboh_equal_entropy_pair.m` (Supplementary Figure S2). Call `make_tanyimboh_equal_entropy_pair('saved')` to redraw the archived pair directly from its full-precision CSVs without a hydraulic run. The node-6 reservoir pair in Supplementary Figure S3 is reproduced from saved data by `networks/tanyimboh_templeman/experiments/node6_reservoir/plot_node6_reservoir_pair.m`; its companion README documents inverse sizing and independent EPANET checking. Figures 2–3 use `networks/y_two_consumers/input/network_original.inp` and their `make_two_consumer_*` scripts. The equal-entropy constructions preserve flows and compare chlorine entropy without a new full-network GA.

## Layout and provenance

- `+wdn/`: shared objective evaluators, STACI calls, ranking and outage utilities, and plotting helpers. The historical name `source_distance_weighted_entropy` is also used for the final branch-hop weights; its supplied weight vector defines the actual objective.
- `networks/<name>/input/`: source and fixed-load INPs; `results_staci*/`: exact designs, numerical summaries, independent ranking caches; `figures_staci*/`: rebuildable network-local graphics (ignored by Git).
- `manuscript/figures/`, `manuscript/tables/`: paper-specific rendering and table exports; `manuscript/generated/`: files consumed by LaTeX.
- `supplementary/`: independent STACI–EPANET replay, stationary-chlorine trajectory, and timing procedures; `supplementary/results/`: released comparison records.
- `third_party/`: EPANET 2.2 library and MATLAB toolkit needed for the independent check.

Use exact saved diameters in validation. Rounding can change feasibility at an active pressure limit. The [STACI MATLAB interface README](https://github.com/hoscsaba/staci/blob/master/matlab/README.md) documents the resident model API, units, and MEX build.
